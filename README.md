# CCA-Prep
**Week 1 .py Explanations**
**Hello.py** - an input to give one response back
**Conversation.py** - user and assistant converse over multiple lines, text is remembered and memory is stored
**System-prompt.py **- character or persona is created to respond in a certain way or manor
**Streaming.py** prints text without consideration of tokens
**Inspect_response.py** response requires check on tokens limit, will "Stop Reason: {max Tokens} and not continue the text
**Structured_output.py ** the use of json - extracts key info from a messy text
